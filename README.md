# Auditorium

**Auditorium** — учебный проект SmartCampus для просмотра занятости университетских аудиторий с учётом расписания занятий и пользовательских отметок.

Репозиторий содержит материалы проекта и средства получения данных расписания. Описание ниже отражает проектируемую логику; детали запуска приложения могут меняться по мере разработки.

## Возможности проекта

- Просмотр статуса аудиторий: свободна или занята.
- Определение занятости с учётом расписания занятий.
- Создание отметки о временной занятости аудитории и её снятие.
- Автоматическое снятие отметок при начале следующего занятия.
- Ограничения на отметки: у пользователя может быть не более одной активной отметки, а у аудитории — не более одной активной отметки.
- Получение расписания с возможностью использовать последнюю успешно сохранённую копию, если источник временно недоступен.

## Основные сущности

| Сущность | Назначение |
| --- | --- |
| `User` | Пользователь системы |
| `Room` | Аудитория и её состояние |
| `ScheduleEntry` | Запись о занятии в расписании |
| `OccupancyMark` | Пользовательская отметка о занятости |
| `RoomStatusService` | Правила определения статуса аудитории и управления отметками |
| `ScheduleParser` | Получение и обновление данных расписания |

При конфликте пользовательской отметки с расписанием приоритет имеет расписание. Снять чужую отметку нельзя.

## Структура репозитория

- `UML/` — UML-диаграммы, описывающие структуру и поведение системы.
- `docs/` — документация и материалы лабораторных работ.
- `src/` — исходный код проекта и инструменты обработки данных расписания.

## Парсер расписания

В репозитории предусмотрен скрипт запуска парсера `run_parser.bat`. В проекте используется Python-окружение и зависимости, перечисленные в `src/parser/requirements.txt`.

Для запуска в Windows из корневой папки репозитория:

```bat
run_parser.bat
```

Скрипт предназначен для установки необходимых Python-зависимостей и запуска парсера. Для работы требуется установленный Python и доступ к источнику расписания.

## UML-документация

В каталоге `UML/` находятся диаграммы вариантов использования, классов, активности и последовательностей. Они помогают понять предполагаемые сценарии работы: создание и снятие отметок, обработку конфликтов и автоматическое освобождение аудиторий.
