# Auditorium

**Auditorium** — учебный проект SmartCampus на C# / .NET для работы с занятостью университетских аудиторий с учётом расписания занятий и пользовательских отметок.

## Возможности проекта

- Определение статуса аудитории с учётом расписания.
- Создание и снятие пользовательских отметок о занятости аудиторий.
- Ограничения на активные отметки: один пользователь может иметь не более одной отметки, а у одной аудитории может быть не более одной активной отметки.
- Запрет на снятие чужой отметки.
- Автоматическое освобождение аудитории по правилам расписания.
- Получение расписания и использование последней успешной копии при временной недоступности источника.

При конфликте пользовательской отметки с расписанием приоритет имеет расписание.

## Технологии

- **C# / .NET 10**
- **ASP.NET Core** — веб-приложение
- **Entity Framework Core** — работа с данными
- **SQLite** — база данных
- **HtmlAgilityPack** — обработка HTML при получении данных расписания

## Структура решения

Решение `Auditorium.slnx` разделено на три проекта:

| Проект | Назначение |
| --- | --- |
| `Auditorium.Web` | Веб-приложение и пользовательский интерфейс |
| `Auditorium.Core` | Основные сущности и логика предметной области |
| `Auditorium.Infrastructure` | Работа с базой данных и внешними источниками данных |

Дополнительные каталоги:

- `UML/` — UML-диаграммы структуры и сценариев работы системы.
- `docs/` — документация и материалы лабораторных работ.

## Требования

- .NET SDK 10.0
- Среда разработки с поддержкой .NET, например Visual Studio или JetBrains Rider

## Сборка и запуск

Из корневой папки репозитория выполните:

```bash
dotnet restore Auditorium.slnx
dotnet build Auditorium.slnx
dotnet run --project Auditorium.Web/Auditorium.Web.csproj
```

После запуска адрес веб-приложения будет указан в выводе консоли. Конфигурация подключения к базе данных и прочие параметры задаются настройками приложения.

## Основные сущности

- `User` — пользователь системы.
- `Room` — аудитория.
- `ScheduleEntry` — занятие в расписании.
- `OccupancyMark` — отметка о занятости.
- `RoomStatusService` — логика определения состояния аудиторий и управления отметками.
- `ScheduleParser` — получение и обновление данных расписания.

## UML-документация

В каталоге `UML/` находятся диаграммы вариантов использования, классов, активности и последовательностей. Они описывают основные сценарии, включая создание и снятие отметок, обработку конфликтов и автоматическое освобождение аудиторий.

## Статус проекта

Проект находится в разработке. Структура и инструкции могут уточняться по мере реализации функциональности.
