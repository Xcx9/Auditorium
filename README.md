# Auditorium

**Auditorium помогает найти свободную аудиторию в МИЭТ.** Это веб-приложение проекта SmartCampus для студентов и сотрудников, которым нужно помещение для самостоятельной работы, встречи или группового занятия. Оно объединяет учебное расписание и отметки о фактической занятости.

## Как это работает

В целевом сценарии пользователь выбирает корпус или вводит часть номера аудитории, открывает карточку подходящего помещения и после входа может отметить его занятым. Свою отметку можно снять досрочно. Если начинается занятие по расписанию, отметка снимается автоматически.

Расписание имеет приоритет. У пользователя и у аудитории может быть по одной активной отметке. Когда на текущую дату нет данных расписания, карточка сообщает об этом вместо статуса «свободна».

## Текущее состояние

В основной ветке есть каркас веб-приложения, модели аудиторий, расписания и отметок, а также слой хранения на SQLite. Поиск и карточка аудитории, регистрация и вход, операции с отметками и автоматическое обновление расписания находятся в разработке.

## Запуск

Установите **.NET SDK 10.0** и выполните из корня репозитория

```bash
dotnet run --project Auditorium.Web/Auditorium.Web.csproj
```

Откройте адрес, указанный в консоли. В основной ветке сейчас открывается стартовая страница ASP.NET Core. Подключение к SQLite задаётся параметром `ConnectionStrings:DefaultConnection` в [настройках приложения](Auditorium.Web/appsettings.json).
