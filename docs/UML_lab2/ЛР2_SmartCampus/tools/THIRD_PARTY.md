# Используемый инструмент

`plantuml.jar` скопирован из установленного официальным механизмом Marketplace расширения `jebbs.plantuml` 2.18.1.

Проверенная версия: PlantUML 1.2024.3; Java OpenJDK 25.0.4; встроенный Graphviz 2.44.1.

- [Страница расширения](https://marketplace.visualstudio.com/items?itemName=jebbs.plantuml)
- [Исходники расширения](https://github.com/qjebbs/vscode-plantuml)
- [Исходники PlantUML соответствующего выпуска](https://github.com/plantuml/plantuml/tree/v1.2024.3)
- [Официальные сведения о лицензии PlantUML](https://plantuml.com/license)

PlantUML сообщает GPLv2 source distribution. Полный вывод лицензии находится в `PLANTUML_LICENSE.txt`.

Пользовательские диаграммы создаются локально. Внешние серверы для генерации не использовались.
